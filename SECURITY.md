# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within OpenCart-MCP, please contact **Anton Barinov** directly via GitHub or report it through GitHub Security Advisories.

All security vulnerabilities are addressed with the highest priority.
